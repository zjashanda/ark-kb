> 2026-11-09 郑保山确认：沿用当前风格，后续新增智能体照此办理。

## 风格

**古制官署名 + 官职**，2–5 字，名实相符。不用现代职级词（经理/主管），也不用宰辅头衔（首辅/宰相/大学士）——那是决策层的名，给执行者会混淆层级。

## 三条硬规则

1. **同一官署下多个智能体**：用不同官职区分（郎中 / 员外郎 / 主事），不要加数字后缀
2. **不占宰辅位**：首辅 / 宰相 / 大学士 / 大司空 只用于"决策层"，执行者不用
3. **改名要同步替换指令正文**：`mention://agent/<uuid>` 不受影响，但 instructions 里的旧名必须一并改

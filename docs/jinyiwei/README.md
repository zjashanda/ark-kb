# 锦衣卫公共操作手册

本分区是所有 `锦衣卫·<节点>` 共享的设备执行知识，不绑定单个节点或单个任务。

## 分层

```text
公共手册：芯片/项目/串口角色/波特率/日志命令/判据/恢复方法
节点快照：当前节点实时 USB 拓扑、板卡、COM、声卡、工具版本
任务配置：本次固件、profile、顺序、设备数量、项目特殊判定
```

公共手册不得写死当前节点 COM 号；COM/tty 必须由任务开始时实时枚举并生成 `port-map.json`。

## 使用顺序

1. 读取任务 Issue 与任务目录。
2. 查询 8091 当前 active 知识并记录 `knowledge_snapshot`。
3. 读取本分区对应芯片/项目操作卡。
4. 枚举当前节点板卡、串口和声卡，合并项目 profile 生成当前任务映射。
5. 再由脚本/采集器执行，锦衣卫读取结构化事件并判定。

## 更新规则

- 新经验先进入知识候选，不直接改 main。
- 必须有 `run_id`、Issue、证据 `uri/bytes/sha256`、适用芯片/项目/固件和独立验证。
- 冲突不覆盖旧卡；标记 superseded 并指向新卡。
- 原始串口日志、音频和大文件留在 8090，手册只保存结论、命令、判据和证据引用。

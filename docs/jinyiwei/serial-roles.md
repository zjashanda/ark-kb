# 锦衣卫串口与音频角色契约

## 串口角色

| 角色 | 公共定义 | 波特率 |
|---|---|---|
| VCOM/Control | 控制窗口；执行 `uut-switch1/2/3/4.on/off` 上下电 | 固定 115200 |
| A | CSK 统一日志口；CSK6/CSK7 都使用；CSK7 也可用 A 烧录 | 按项目 profile |
| B | CSK6 烧录口；CSK7 不使用 | 按项目 profile |
| C | HISI/上位机日志和烧录；非 HISI 时记录实际上位机角色 | 按项目 profile |
| D | CSK6 CP 日志；CSK7 不使用 | 按项目 profile |

A/B/C/D 是逻辑角色，不是固定 COM 号。每次任务必须通过 USB/PnP/CH344/CH348/Container ID 重新枚举，生成当前任务 `port-map.json`。

## 音频角色

- 默认播报使用当前节点默认播放声卡。
- 任务明确指定时才切换播放端点。
- 录音声卡独立识别，不把录音端点当播放端点。
- 记录端点稳定 Key、设备名、通道数、采样率、音频文件 SHA 和播放/录音时间窗。

## 证据

串口原始日志由采集器持续写入；锦衣卫读取 `events.jsonl` 摘要。没有原始日志或结构化事件引用，不得判 PASS。
